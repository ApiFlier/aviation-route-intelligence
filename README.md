# FlightConn

A flight route, airline operations, fare, and airline career/health dashboard built from BTS aviation datasets. Shows route traffic, carriers, fares, on-time performance, airline workforce, financials, hubs, network size, and fleet data.

**Live site:** http://localhost:8082  
**Career page:** http://localhost:8082/career/

---

## Deploy

### Part 1 — Install Docker

```bash
sudo apt update && sudo apt upgrade -y && sudo apt install -y git curl openssl netcat-openbsd
curl -fsSL https://get.docker.com | sh && sudo usermod -aG docker $USER
```

Log out and back in, then verify:

```bash
docker --version && docker compose version
```

### Part 2 — Clone and run

```bash
git clone https://github.com/ApiFlier/FlightConnections.git ./flightconn && cd ./flightconn && chmod +x setup.sh && ./setup.sh
```

`setup.sh` will:

- Generate a `.env` file with random passwords and an available port (default 8082)
- Build and start the **FlightConn App** and **MySQL** containers
- Wait for MySQL to pass its health check
- Restore the database from `api/Data/db_backup.sql.gz` if empty
- Verify the app and API are responding
- Print the live URL

---

## After setup

```bash
# View running containers
docker compose ps

# Stream logs
docker compose logs -f

# Create a database backup
./backup.sh

# Restore a database backup
./restore.sh backups/flightconn_YYYYMMDD_HHMMSS.sql.gz

# Stop the application
docker compose down
```

## Tech stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML5, Vanilla JS, Leaflet.js, Font Awesome |

| Database | MySQL 8.0 |
| Orchestration | Docker Compose |

## Project structure

```

├── docker-compose.yml          # Orchestrates app + db
├── setup.sh                    # One-command deploy script

├── restore.sh                  # Restore a DB backup
├── .env                        # Generated by setup.sh (not in git)
├── frontend/                   # UI assets (served by Flask)
│   ├── index.html              # Leaflet map UI
│   ├── config.js               # API URL config (points to /api)
│   ├── js/api.js               # Fetch wrapper
│   └── career/index.html       # Career/airline health page
└── api/
    ├── Dockerfile              # Builds the 'app' image
    ├── main.py                 # Flask entry point (UI + API routes)
    ├── requirements.txt
    ├── Data/
    │   └── db_backup.sql.gz    # Initial data restore file
    ├── Modules/
    │   └── ...                 # API route blueprints
    └── Classes/
        └── ...                 # Database and processing logic
```

## Ports

`setup.sh` auto-discovers an available port for the app (starting at 8082).

| Container | Internal port | External port |
|-----------|---------------|---------------|
| flightconn-app | 8080 | ${APP_PORT} (default 8082) |
| flightconn-db | 3306 | (Internal only) |

---

## Full reset (Deletes all data)

```bash
docker compose down -v   # removes containers and the MySQL data volume
./setup.sh               # rebuilds everything from backup
```
